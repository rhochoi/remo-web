## 켜는 절차 (엔드포인트 확보 후)

1. `site/index.html`의 `<form data-endpoint="https://formspree.io/f/FORM_ID">` 에 실제 ID
2. `<section id="contact" hidden>` 에서 `hidden` 제거
3. 헤더 내비에 `<a href="#contact">문의</a>` 추가
4. Formspree 대시보드: reCAPTCHA 끄기, 수신 메일 확인, 테스트 제출 1건
5. 최소 공개 단위 ④ 충족 → 팀원 포지션(③)까지 오면 `noindex` 제거

## Formspree 쪽에서 팀이 할 일

- formspree.io 가입 → New form → 수신 이메일(팀 공용 권장) → 폼 ID(`xxxxxxxx`) 전달
- Settings에서 reCAPTCHA 비활성화
- 무료 티어 월 50건 — 초과 시 유료. 초과가 문제가 되는 날은 좋은 날이다
