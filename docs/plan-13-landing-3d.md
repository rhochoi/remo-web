## 2. 프로토타입이 보여 주는 것 (실행·검증됨)

1. **풍선 로고.** 실제 `remo-wordmark.png`의 알파를 블러해 높이로 쓰는 절차적 모델링. 앞·뒤 두 장을 맞붙여 부푼 덩어리를 만든다. 둥근 매스와 기울기 같은 로고의 손맛이 원본 비트맵에서 그대로 온다.
2. **두 폴 전환.** 소프트(주황·무광·종이 배경) ↔ 글로시(블루 틴트 크롬·어두운 배경). 버튼으로 전환, 진입 시 0.9초 부풀기(오버슈트 없는 ease-out).
3. **상호작용.** 포인터를 따라 기울기, 누르면 눌렸다 돌아오는 감쇠 스프링 한 번, 대기 중 미세한 떠오름.
4. **관계 그래프.** `site/data/relations.json`의 노드 10개와 간선을 3D로. 유형 버튼으로 간선이 자라며 바뀌고, 연결된 노드는 커지고 나머지는 작아진다. 노드에 호버하면 "이 사람은 ○○ 관계가 N개" 읽기. 모든 정보는 버튼과 `aria-live` 텍스트로도 얻을 수 있다.
5. **방어.** reduced-motion에서 부풀기·떠오름·간선 성장 정지. 화면 밖이면 렌더 중단. WebGL 실패 시 정적 로고로 대체(코드 경로만 있고 실제 실패 상황은 시험하지 않음).

확인한 것: 데스크톱 브라우저 창에서 두 모드·간선 전환·읽기 문구 동작, 콘솔 오류 0. 확인하지 못한 것은 §6.

## 3. 팀에 맞는 랜딩 구성 (제안)

골격은 기존 IA를 유지하고(원페이지, 파격은 첫 화면에만), 3D는 **두 군데에만** 쓴다. 나머지는 정석이다.

| # | 섹션 | 방문자가 하는 일 | 모션·3D | 상태 |
|---|---|---|---|---|
| 0 | **첫 화면: 풍선 로고** | 로고를 밀고 눌러 본다 | 3D. 정지 포스터 이미지가 먼저 뜨고(LCP) 유휴 시간에 캔버스로 교체 | 프로토타입 있음 |
| 1 | 하는 일 3가지 | 읽는다 | 기존 CSS 진입만 | 배포됨 |
| 2 | **관계 맵: 열 명이 맞물린 방식** | 유형을 골라 선이 바뀌는 걸 본다 | 3D. 첫 화면에서 로고가 열 개의 구체로 갈라지는 스크롤 전환은 2단계 | 그래프 프로토타입 있음, 전환은 미구현 |
| 3 | 프로젝트 4개 | 근거를 본다 | 사진 카드 호버만. 3D 없음 | 배포됨 |
| 4 | 받는 일 / 받지 않는 일 | 자기가 대상인지 판단 | 없음 | 문구 합의 대기 |
| 5 | 팀 | 이름을 본다 | 없음. 이름과 노드를 연결하지 않는다(plan-06) | 배포됨 |
| 6 | 문의 | 시간을 들여 쓴다 | 없음. 폼은 조용해야 한다 | 배포됨 |

서사: "한 덩어리의 로고가 열 명으로 갈라지고, 서로 맞물린 방식이 선으로 드러난다." 이 문장은 가이드의 "각자의 형태를 잃지 않은 채 하나로 맞물린 흔적"을 그대로 시각화한다.

## 5. 라이브러리 도입 기록 (D2 승인 시 적용)

- 이름: three.js r160(MIT). 프로토타입은 jsDelivr CDN의 비압축 모듈을 쓴다. 실제 도입 시 `three.module.min.js`를 셀프호스팅하고 필요한 모듈만 번들한다.
- 용량: min 빌드 gzip **약 166KB**(2026-10-08 jsDelivr 응답 측정). 환경맵은 코드로 생성(`studio()`)해 HDR 파일이 없다. 로고 마스크는 기존 PNG 재사용. 전체 JS 예산 대비 비율은 번들 후 측정 필요.
- 대체 불가 사유: 실제 반사와 부푼 곡면. CSS로는 근사만 된다.
- 로딩: 첫 화면 정지 포스터 → `requestIdleCallback` 후 동적 import → 교체. 화면 밖이면 렌더 중단.
- 제거 조건: LCP 2.5s 또는 INP 200ms 예산을 어기거나, 필터 효과(문의 질)가 측정에서 없을 때.

## 6. 이 프로토타입이 하지 않는 것 (정직한 한계)

- **손으로 조각한 모델이 아니다.** 로고 비트맵에서 절차적으로 부풀린 것이다. 앞뒤 가장자리에 얇은 접합선이 보이고(소프트 모드), 크롬 반사는 실제 스튜디오 조명이 아니라 소프트박스 몇 장이다. 출시 품질은 Blender 조각 후 `.glb` 내보내기를 권한다. 나는 이 세션에서 Blender를 실행하지 않았다.
- 로고 → 열 개 구체 **스크롤 전환은 만들지 않았다.**
- **성능을 측정하지 않았다.** 모바일 실기기, 저사양 GPU, LCP·INP는 미측정. 이 세션은 한 대의 데스크톱 브라우저 창에서만 봤다.
- 터치 제스처, 키보드로 3D 조작은 미구현(대신 버튼으로 같은 정보를 얻는다).
- `cover`·`collab` 간선은 방향이 있으나 프로토타입은 방향을 그리지 않는다.
- 사이트 본체(`site/index.html`)는 바꾸지 않았다. 코드는 `site/lab/` 안에서만 산다.
