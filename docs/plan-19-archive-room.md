# 계획 19 · 내부 기록실(`/search`) 화면

날짜: 2026-10-15. 코드: `site/search.html`(단일 파일), `api/search.js`, `api/ask.js`. 홈 같은 포트폴리오가 아니라 팀이 쓰는 도구라서 아래 결정은 이 화면에만 적용한다.

규칙은 [REMO-OVERRIDES](../.claude/skills/REMO-OVERRIDES.md)와 `redesign-existing-projects` 감사 순서(진단 → 수정 → 재검증)를 따랐다. 다이얼은 홈과 같은 DESIGN_VARIANCE 6 · MOTION_INTENSITY 3 · VISUAL_DENSITY 3을 쓰되, 작업 도구라서 움직임은 등장 0.22초와 로딩 숨쉬기뿐이다.

## 점검

- 글자 대비 전부 AA 이상: muted/white 5.41, orange-text/paper 6.38, white/ink 17.40, 근거 발췌 10.34.
- 키보드: 건너뛰기 링크, 포커스 링(주황 3px), 모드 라디오 포커스 표시, Enter 전송(한글 조합 중 제외) 확인.
- `prefers-reduced-motion`에서 모든 애니메이션과 전환을 끈다.
- 500자 제한: 400자부터 글자 수를 보여주고 500자에서 강조한다(서버 제한과 같음).
- 배포 전 확인 못 한 것: 실제 Gemini 답의 형식. 인용을 `[n]` 이외 형식으로 쓰면 칩 대신 글자로 보인다.

## 재검토 조건

- 주소가 팀 밖에 퍼졌거나 이상한 호출이 보이면 접근 통제를 다시 둔다(공유 비밀번호, 또는 팀 로그인). `private` 표시는 이메일·전화번호 등 키워드 규칙과 직접 지정한 경로만 잡으므로, 그 밖의 내부 내용은 주소를 아는 누구나 볼 수 있다.

- 팀원이 이전 질문을 다시 보고 싶다는 요구가 반복되면 저장 방식(서버 저장, 접근 통제 포함)을 새로 결정한다.
- 근거 문서에 발췌 외 원문 보기가 필요해지면 문서 상세 보기를 추가한다(지금은 경로와 발췌만 제공).
