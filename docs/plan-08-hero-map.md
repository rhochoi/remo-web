# 계획 08 — 첫 화면: 정의문 + 관계 맵

형식: 결정 / 이유 / 근거 / 기각안 (+ 재검토 조건). 질문: "문제를 받아 실행으로 증명하는 열 명의 학생 협동조합"을 글자 말고 무엇으로 보여줄 수 있는가.

## 2. AI Council 강등 사유 3개의 해소 (첫 화면 복귀의 근거)

| 강등 사유 (2026-09-17) | 지금 |
|---|---|
| `role="img"`로 보조기기에 상호작용 없음 | 노드 `<button>`, `aria-pressed`, `aria-label`(익명 번호·연결 수), `role="status"` 문장 |
| 실데이터 없음 = 지어낸 시각화 | 실데이터(REMO OS v4.1), 본인 동의 완료, 긍정 3유형 |
| 내부 진단 용어 라벨 | 외부어 5개로 번역·승인 |

+ 방문자 대변인의 "첫 화면에 정의문 한 줄"은 **유지**한다. 글자와 도구는 대체가 아니라 분업: 글자가 "무엇을 하는 누구"를 3초에, 도구가 "열 명이 어떻게 맞물렸는가"를 만지는 동안.

## 3. 결정

| 항목 | 결정 | 이유 | 근거 | 기각안 |

## 4. 검증 (2026-09-18)

375px: 스테이지 하단 415 < 664, 가로 넘침 없음, 노드 최소 32px, 상태 문장 출력. 1280px: 2열 528/528, h1 59px 3줄, 가로 넘침 없음.

## 6. 개정 (2026-09-18 저녁) — 글자를 뺀다

팀장 결정: "보고 느낄 수 있게, 설명하지 말 것." 첫날 결정(decisions 2026-09-17 "헤드라인 대신 작동하는 도구")과 가이드 v4("로고는 설명하지 않고 작동 방식을 재현한다")로 돌아간다.

| 항목 | 결정 | 이유 | 근거 | 기각안 |
|---|---|---|---|---|
| 첫 화면 | 관계 맵이 화면을 채운다 (`100dvh − 헤더 − 여백`, 390px 실측 80→804). 보이는 글자는 필터 3개와 출처 캡션(데스크톱만, 13px)뿐 | 설명하지 않고 재현한다 | 팀 결정 · 가이드 v4 · decisions 첫날 | 정의문 + 맵(§3) — 회의 권고였으나 팀장이 "설명"으로 판단 |
| h1 | DOM에 유지, 시각적으로만 숨김(`.sr-only`) | 보조기기·검색엔진에는 "무엇을 하는 누구"가 여전히 첫 정보. 이건 설명이 아니라 눈으로 못 보는 사람에게 같은 페이지를 주는 것 | WCAG 2.4.6 · 1.3.1 | h1 삭제 — 문서 제목이 없어짐 / 보이는 h1 — 팀 결정과 충돌 |
| 상태 문장 | `.sr-only` + `role="status"` | 시각 사용자는 선의 변화로 느끼고, 보조기기 사용자는 문장으로 듣는다 — 같은 정보, 다른 감각 | WCAG 4.1.3 | 보이는 상태 문장 — "관계 9개, 상위 3명" 자체가 설명 |
| 필터 | 매스 안 왼쪽 아래, 이름만(정의문 숨김) | 만지는 손잡이는 남긴다. 정의 한 줄은 설명이라 뺀다 | 팀 결정 | 정의문 표시 — 라벨이 관계 서술구라 라벨만으로 읽힘 |
| 출처 캡션 | 매스 안 오른쪽 위 13px, 모바일은 숨김 | 눈금 원칙(표본·시점)은 지키되 각주 크기로. 모바일은 면적이 없음 | README 콘텐츠 기준 | 모바일에도 — 노드 영역을 침범 |
| 선 좌표 | `preserveAspectRatio="none"`, 노드도 같은 사각형(%)에 배치 | 스테이지 비율이 화면마다 달라도 선 끝과 노드 중심이 일치(실측 ±2px) | 실측 | 비율 고정 스테이지 — 화면을 못 채움 |
| 노드 호버·포커스 | `scale(1.12)` 150ms, reduced-motion 시 없음 | 노드는 버튼이다. "만질 수 있다"는 어포던스 — 장식이 아니라 정보 | 어포던스 · plan-01 움직임 예산 | 없음 — 첫 방문자가 만질 수 있는지 모름 |

**위험(기록)**: AI Council 방문자 대변인의 "30초 안에 무엇을 하는 팀인지 모르면 떠난다"는 우려는 해소된 것이 아니라 **팀장이 감수하기로 한 것**이다. 측정 장치: 필터 전제 기각 조건(2026-12-31, 문의 N건). 그때까지 이 첫 화면을 유지한다.
