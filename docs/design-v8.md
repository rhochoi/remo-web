# v8 — 먼저 설명하지 않는 화면

2026-09-18. 사용자 방향: 사람과 관계가 중심이며 처음에 모두 이해할 필요는 없다.

첫 화면의 정체성 문장·프로젝트 설명·방문자에게 읽는 법을 가르치는 문구 제거. 사람들의 실제 장면 두 개를 앞에 놓고 날짜만 표시. 작업 사진은 동일한 회색 프레임에서 해방하고 매체 비율 그대로 배치. 큰 프로젝트 제목·단락별 설득문을 제거하고 작은 이름과 참여자, 실제 팀 인용을 남김. 설명과 출처는 native details로 선택해서 읽는다. 관계나 발언을 새로 만들지 않는다.

사진 확대의 대체 텍스트·키보드 조작·Escape·초점 복귀는 유지. 리모 소개로 이동하면 해당 항목이 열린다. 6개 너비 및 이미지 로드·확대, 출처 펼침, 소개 열기, no-JS 정보 열람, axe 검사 통과. 데스크톱과 모바일 시각 검토 완료.

이전 화면은 archive-before-v8 보존. 외부 게시/push 없음. 새 촬영 자료 없이 서로 다른 사람의 관계를 깊이 표현하는 데에는 여전히 한계가 있다.
