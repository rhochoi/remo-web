# 리모 웹 디자인 원칙 v5

2026-09-17 · 현재 홈페이지에 적용한 해석. 팀이 공식 승인한 새 브랜드 선언이 아니다.

## 근거와 판단

기존 브랜드 가이드의 핵심은 장난기·유연함·대담함, 그리고 서로 다른 형태의 연결이다. 원본 로고의 비정형 글자, 사용자의 오션 블루 유지·불필요한 문구 삭제 요청을 우선한다. 로고가 둥글다는 이유만으로 모든 정보에 버블·3D·크롬을 붙이는 것은 논리적 비약이다. 사진은 행동의 증거이며 성공이나 개인 성격의 증거는 아니다.

MengTo documentary-brutalist-agency에서는 실제 사진, 이야기 순서와 DOM 순서 일치, 접근 가능한 열기/닫기를 채택했다. 거대 제목·흑백·각진 외관은 채택하지 않았다. html-to-interaction-prompts에서는 동작의 목적과 상태, 키보드·터치 대응을 먼저 정의하는 방식을 채택했다.

## 기본 이론을 실제 화면으로 연결

- 위계: 로고는 누구인지, 사진은 무엇을 하는지, 프로젝트명은 무엇을 찾아볼지 전달한다. 모든 글자를 크게 하지 않는다.
- 근접성: 프로젝트명·설명·참여자·기록을 같은 항목에 묶는다. 사람 이름에서 해당 프로젝트로 직접 이동한다.
- 반복과 대비: 기본 여백과 곡률은 반복한다. 서로 다른 작업 내용과 원본 로고가 차이를 만든다. 임의 기울기나 성격별 색상은 쓰지 않는다.
- 점진적 공개: 한 줄 설명은 항상 보이고 단계와 기록은 펼쳐 본다. 방문자가 클릭하기 전에도 프로젝트 내용을 알 수 있어야 한다.
- 행위의 예측 가능성: 링크는 이동, 원형 +/−는 펼침, 사진의 확대는 원본 보기다. 닫기는 명확히 표시하고 Escape와 포커스 복귀를 지원한다.

## 요소별 사용 규칙

| 요소 | 구체적인 규칙 | 존재 이유 |
|---|---|---|
| 로고 | 원본 PNG 비율·색·윤곽 유지. 투명 여백만 CSS에서 제외. 데스크톱 160px, 모바일 128px. 상단 한 번만 사용 | 비정형 글자 자체가 장난기와 연결을 표현. 반복·회전·늘임으로 의미를 덧붙이지 않음 |
| 로고 여백 | 상단 헤더 내부에 독립된 공간, 이미지나 텍스트를 로고 위에 겹치지 않음 | 글자 덩어리의 실루엣을 온전히 읽게 함 |
| 파랑 | #1E548C, 로고·프로젝트명·링크·활성 컨트롤 | 브랜드 식별과 행동 위치를 함께 전달 |
| 바탕 | #F8F8F6, 본문은 어두운 잉크 | 사진의 실제 색을 보존하고 읽기 대비 확보 |
| 사진 면 | 동일한 24px 곡률. 서로 다른 모서리의 64px 곡률 제거 | 실제 내용을 여는 부드러운 영역이라는 공통 규칙 |
| 원 | 44px 원형 +/−에만 사용 | 누르는 위치와 펼침 상태 표시. 장식 원은 없음 |
| 선 | 프로젝트·사람·푸터 사이 1px 구분선 | 반복 정보의 경계를 구분. 배경 격자와 가짜 기술 장식은 없음 |
| 타이포 | 기존 Pretendard 유지. 프로젝트명 24–36px, 본문 16–17px, 캡션 14–15px | 로고와 경쟁하지 않는 한글 가독성. 구체적 탐색 대상만 강조 |
| 큰 제목 | 선언형 히어로 제목 없음 | 사진과 실제 작업을 뒤로 밀어내지 않음 |
| 작은 문자 | 날짜·사진 맥락·정보 기준일에 한정 | 사진 출처 맥락과 정보의 시점을 전달 |
| 여백 | 본문 대단락 88px, 모바일 56px. 캡션 16px | 단락 간 구분과 사진/캡션의 결합을 동시에 표현 |
| 사진 클릭 | 원본 비율의 모달, 닫기 버튼·Escape·외부 클릭 | 크롭으로 보이지 않는 실제 기록을 확인 |
| 프로젝트 클릭 | native details/summary, +가 −로 변경 | 회전 ×를 없애 닫기/삭제 기호 혼동 방지 |
| 인물의 프로젝트 링크 | 확인된 참여 관계만 표시, 대상 항목 자동 펼침 | 개성을 추측하는 태그 대신 실제 기여의 탐색 경로 제공 |
| hover/focus | 행 배경·밑줄·명시적 초점 테두리 | 어떤 영역이 반응하는지 표시. 위치 이동 없음 |
| 움직임 | 색 상태 전환 180ms만 사용. reduced-motion에서는 제거 | 피드백 제공. 읽기와 스크롤 통제권 보존 |
| 외부 링크 | 노션 기록으로 이동, 화살표 표기 | 내부 펼침과 외부 이동 구분 |

## 아직 해결하지 못한 것

현재 사진 두 장만으로 리모의 장난기나 각자의 작업 방식을 충분히 설명할 수 없다. 확인된 사람-프로젝트 관계가 없는 칸은 비워 두며 활동이 없다는 뜻이 아니다. 실제 초안→수정본과 당사자의 짧은 설명이 확보되면 해당 프로젝트 내부에 추가한다. 가짜 스케치·후기·성과 수치는 넣지 않는다.
