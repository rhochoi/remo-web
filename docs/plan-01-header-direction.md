## 1. 방향

| 항목 | 결정 | 이유 | 근거 | 기각안 |
|---|---|---|---|---|
| 위계 | 미션(56) > 비전(32, 잉크 블록) > 가치(18, 블루 필) > 분기 목표(24, 아웃라인 카드) + 의사결정(15) | 미션은 이 섹션의 1순위지만 **h1보다 작아야** 페이지 위계가 유지됨(72 > 56). 나머지는 컨테이너를 달리해 "세 가지 정보"로 분리 | 시각 위계 · 게슈탈트 공통영역 | 미션 72px — v1 계획. h1과 같은 크기라 페이지에 1순위가 둘 |
| 아이브로 | "01 — 왜, 무엇을, 어디로" 15px 700 블루, 자간 0.08em | 섹션 번호로 위치 감각. 소문자 영문이 아니라 국문이므로 자간은 약하게 | 블루 on 근백색 7.31:1 | 영문 "DIRECTION" — 국문 사이트에 영문 라벨 이유 없음 |
| 출처 캡션 | "리모(REMO) 협동조합의 미션. 팀 노션에 기록된 문장 그대로다." 18px 캡션색 | "눈금 붙은 수치" 원칙을 문장에도 적용 — 어디서 온 문장인지 밝힘 | README 콘텐츠 규칙 | 없음 — 미션이 사이트용 카피로 오해됨 |
| 레이아웃 | ≥880px: `grid-template-columns: 560px 1fr`, 좌 비전 블록 / 우 가치+분기목표. <880px: 1단 | 비전 블록이 32px 국문 2~3줄을 담으려면 560px 필요. 그 아래로는 2단이 깨지므로 880에서 끊음(560 + 32 gap + 최소 288) | 콘텐츠 기준 브레이크포인트 | 768px(기기 기준) — 비전 블록이 480px로 줄어 4줄 넘김 |
| 비전 블록 기울기 | `rotate(-1deg)`, 이 섹션의 **유일한** 기울기 | 형태 앵커 "상승 기울기". 화면당 강한 제스처 1개. 가장 무거운 요소(잉크 블록)에 준다 | README 형태 앵커 · 디자인 정책 1~2개 | 가치 필에도 ±1/-2deg — v1 계획. 기울기가 3곳이면 제스처가 아니라 소음 |
