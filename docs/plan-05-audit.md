# 계획 05 — 현재 사이트 감사 (redesign 프로토콜)

도구: `.claude/skills/redesign-existing-projects` 체크리스트 + `design-taste-frontend` 4.7/9장 + `REMO-OVERRIDES.md`.
대상: `site/index.html` (커밋 `26e6df9`, 2026-09-18). 측정은 grep·계산·375/1280 에뮬레이션.
판정은 세 가지: **고침**(스킬 지적이 타당) / **유지**(리모 결정과 충돌, 근거 있음) / **충족**(이미 그렇게 돼 있음). 고침·유지에는 이유와 재검토 조건을 붙인다.

## 1. 스캔

순수 HTML/CSS, JS 15줄×2(현재 섹션 표시, 폼 AJAX), 라이브러리 0, Pretendard dynamic-subset. 섹션 5(문의 hidden), 헤더 sticky, 푸터.
