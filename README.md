# remo-web

REMO 팀 웹사이트. 배포: https://rhochoi.github.io/remo-web/ (현재 `noindex`, 최소 공개 단위 충족 전)

## 이 사이트가 하는 일

설득이 아니라 **필터**. 맞지 않는 방문자를 빠르게 내보내고, 맞는 방문자에게 확신을 준다.
성공 지표는 문의 수가 아니라 문의 대비 계약률.
기각 조건: 2026-12-31까지 유효 문의 N건 미만이면 이 전제를 재검토한다 (N은 팀이 정한다).

## 구조

- `site/` — 배포되는 정적 사이트 (GitHub Pages가 이 폴더만 본다)
- `docs/` — 구조(IA), 결정 기록, 섹션별 계획 (배포되지 않음)
- `.claude/skills/` — 팀이 공유하는 AI 디자인 스킬 + 리모 오버라이드
- `.github/workflows/pages.yml` — main 푸시 시 자동 배포

## 규칙을 쓰는 방식

이 문서에 "금지"는 없다. 모든 규칙은 **조건 + 이유 + 재검토 조건**으로 쓴다.
금지는 판단을 대체하지만, 조건은 상황이 바뀌면 다시 판단하게 만든다.
디자인 결정은 `docs/plan-*.md`에 **결정 / 이유 / 근거 / 기각안** 4칸으로 기록한다. 한 칸이라도 비면 임시값이다.

## 콘텐츠 기준

| 기준 | 이유 |
|---|---|
| 없는 사례·수치·후기는 만들어 채우지 않는다 | 채우는 순간 이 사이트 전체가 거짓말이 된다 |
| 모든 수치에는 표본 수, 측정 시점, 측정 방법을 붙인다 | 눈금 없는 수치는 검증 불가 |
| 비어 있는 값은 비어 있는 채로 둔다. 다만 자리표시 `[ ]`는 공개 페이지에 두지 않는다 | 내부적으로는 정직하지만 외부인에게는 미완으로 읽힌다. 비어 있으면 요소 자체를 렌더링하지 않거나, 왜 비어 있는지 한 문장으로 밝힌다 |
| 노션 원문을 그대로 쓰는 문장(미션·비전·가치·분기 목표)은 노션이 바뀌면 사이트를 바꾼다 | 출처가 하나여야 어긋나지 않는다. 사이트에서 먼저 고치지 않는다 |

## 기술 기준

| 기준 | 이유 | 재검토 조건 |
|---|---|---|
| 3D / WebGL / Spline은 첫 화면 밖에서 lazy-load하고, JS 예산 안에 들고, reduced-motion 시 정적 대체가 있을 때 쓴다 | 히어로에 넣으면 JS 800KB~2MB로 LCP 2.5s를 넘긴다 | 390px 실기기에서 FPS 30 이상, LCP 2.5s 이하로 측정되면 첫 화면 사용도 재검토 |
| `backdrop-filter`는 고정 요소(헤더 등) 한 곳까지 | 스크롤 컨테이너 안에서는 프레임마다 재합성돼 실사용 기기 FPS가 15~30% 떨어진다 | 실기기 측정에서 하락이 5% 미만이면 확대 |
| 부드러운 스크롤 라이브러리는 네이티브 `scroll-behavior`로 안 되는 연출이 생겼을 때 쓴다 | 그 전에는 라이브러리가 해결하는 문제가 없다. 번들만 는다 | 스크롤 연동 연출(관계 맵 등)이 결정될 때 |
| 390px에서 가로 스크롤이 생기지 않아야 한다 | 실사용 기기의 하한. 가로 스크롤은 레이아웃 실패의 가장 흔한 신호 | 없음 — 커밋마다 실측 |
| `prefers-reduced-motion`을 존중하고, 키보드 포커스를 표시하고, 텍스트 명암비 4.5:1 이상(24px+ 대형은 3:1) | WCAG 2.2 AA. 명암비는 상대휘도식으로 계산해 수치를 문서에 남긴다 | WCAG 갱신 시 |
| 첫 화면의 모든 콘텐츠는 390×664에서 스크롤 없이 도달 가능해야 한다 | 첫 화면이 잘리면 무엇을 하는 팀인지 알기 전에 떠난다 | 없음 |
| 예산: 폰트 합계 ≤300KB, LCP ≤2.5s, INP ≤200ms, 라이브러리 0이 기본 | 정적 원페이지에 프레임워크가 해결하는 문제가 없다 | 스크롤 연동 연출이나 상태 관리가 필요한 섹션이 생길 때 |
| 라이브러리를 쓰기로 했다면 이유·용량·대체 불가 사유를 `docs/plan-*.md`에 기록한다 | 기록 없는 의존성은 나중에 왜 있는지 아무도 모른다 | — |

## 현재 상태

배포됨 (`noindex`). 렌더링 순서: 정의문 → 01 방향 → 02 포트폴리오 → 03 팀 → (문의: Formspree 폼 ID 대기, hidden)

첫 화면은 정의문 한 줄: "문제를 받아 실행으로 증명하는 열 명의 학생 협동조합, 리모."
무텍스트 관계 맵은 조건부 섹션으로 강등 — 사유와 재도입 3조건은 `docs/structure.md`.
