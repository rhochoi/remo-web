# remo-web

REMO 팀 웹사이트.

## 이 사이트가 하는 일

설득이 아니라 **필터**. 맞지 않는 방문자를 빠르게 내보내고, 맞는 방문자에게 확신을 준다.
성공 지표는 문의 수가 아니라 문의 대비 계약률.

## 구조

- `site/` — 배포되는 정적 사이트 (GitHub Pages가 이 폴더만 본다)
- `docs/` — 브랜드 가이드, 기획 결정 기록 (배포되지 않음)
- `.github/workflows/pages.yml` — main 푸시 시 자동 배포

## 디자인 하드룰 — 브랜드 가이드 v4

- 컬러: `#0A0A0A`(잉크) / `#1E548C`(오션 블루) / `#F8F8F6`(근백색)
- 이 사이트는 **블루 모드 단일 운용**. 오렌지(`#FA7000`)는 한 픽셀도 쓰지 않는다
- 형태 앵커 3개 — 둥근 통통한 매스 / 상승 기울기와 손맛 / 단색 고대비
- 라운드 20px 미만 금지, 얇은 획 금지, 각진 처리 금지
- 균등 그리드 금지, 전체 가운데 정렬 금지. 기울기는 -2deg / -1deg / +1deg 세 값만
- 워드마크 "REMO"는 커스텀 레터링이다. 폰트로 타이핑하거나 AI로 생성하지 말 것
- 국문 제목: `word-break: keep-all`, `letter-spacing: -0.03em`

## 콘텐츠 규칙

- 없는 사례, 없는 수치, 없는 후기를 만들어 채우지 않는다
- 모든 수치에는 표본 수, 측정 시점, 측정 방법을 붙인다
- 비어 있는 값은 비어 있는 채로 둔다. 채우는 순간 이 사이트 전체가 거짓말이 된다

## 기술 기준

- 3D / WebGL / Spline 허용
- backdrop-filter 허용
- 부드러운 스크롤 라이브러리 허용
- 390px에서 가로 스크롤 금지
- `prefers-reduced-motion` 존중, 키보드 포커스 표시 필수, 명암비 4.5:1 이상
- 첫 화면의 모든 콘텐츠는 스크롤 없이 도달 가능해야 한다

## 현재 상태

v0 — 기획 단계.

첫 화면 방향: 무텍스트 관계 네트워크 맵. 헤드라인 대신 작동하는 도구를 놓는다.
방문자가 노드를 만지는 순간 리모가 뭘 하는 팀인지 스스로 알게 된다.

### 미해결

- 로고 벡터 원본 미확보 (래스터만 있음) — 이것 없이는 완성 불가
- 팀 진단 데이터 익명화 기준 미정 — 외부 공개 전 본인 동의 필요
- 사례 3개 중 1개만 확보
- "받지 않습니다" 문구 팀 합의 미완료
